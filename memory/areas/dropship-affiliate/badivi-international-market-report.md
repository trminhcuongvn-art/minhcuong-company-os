## 3. Tools nên thêm để tăng traffic quốc tế

Ưu tiên tools có **search demand thật** và **static/client-side khả thi**.

### Tier A — build immediately, high demand + client-side

| Tool | Evidence/demand | Static/client-side feasibility | Target markets |
|---|---|---|---|
| TikTok downloader localized pages | AhrefsTop: ssstik 41.4M visits; snaptik 20.5M; Indonesia keywords 23M–24M | Core download may need backend/proxy; landing/static SEO pages possible | Indonesia, Brazil, PH, MX |
| JPG to PDF | AhrefsTop ilovepdf India `jpg to pdf` 4.8M; smallpdf US 168K | Yes: browser canvas/PDF lib | India, US, Brazil, LatAm |
| PDF to JPG | smallpdf US `pdf to jpg` 190K | Yes with pdf.js | US, India, global |
| Compress image / PNG/JPG/WebP | Competitors: Squoosh, imagecompressor, TinyPNG; universal demand | Yes via browser codecs/wasm | US, Brazil, India |
| QR code generator | Evergreen high intent; monetizable business users | Yes | US, PH, Brazil, LatAm |
| Password generator | High CPC security-adjacent; 1Password/Bitwarden rank | Yes | US, UK/CA/AU later |
| EXIF remover / image metadata remover | Privacy long-tail, lower competition | Yes | US/EU |
| UUID/GUID generator | Dev recurrent use, static | Yes | US/India/dev markets |
| JSON formatter/validator | Large dev demand, recurring | Yes | US/India/global |
| Case converter / word counter / text cleaner | Low competition long-tail; content users | Yes | Global |

### Tier B — high demand but more engineering / server-side

| Tool | Demand evidence | Challenge | Recommendation |
|---|---|---|---|
| PDF to Word | AhrefsTop India `pdf to word` 4M, `pdf to word converter` 1.5M | Accurate conversion server-side/OCR | Start with simple text extraction; later premium accurate converter |
| Compress PDF under 100KB/200KB | India exam/gov long-tail | Browser PDF compression limited | Build partial client-side; server-side for heavy files |
| OCR image to text | High utility, affiliate potential | WASM OCR heavy | Add later with Tesseract.js, cap file size |
| Remove background | Huge demand, monetizable | ML/server cost | Not first 90 days unless API budget |
| YouTube downloader | Demand high but policy/legal/ad risk | Risky | Avoid for AdSense safety |

### GitHub/open-source trend alignment

Static/browser-side utilities are supported by mature OSS stacks:
- Image: `squoosh` codecs, `browser-image-compression`, `sharp` if server-side.
- PDF: `pdf-lib`, `pdf.js`, `jsPDF`.
- QR: `qrcode`, `qr-code-styling`.
- Text/dev: JSON formatter libs, UUID libs.
- Password: Web Crypto API only, no server.

**Recommendation:** BaDiVi nên định vị rõ: **“Free tools that run in your browser — fast, private, no signup.”** Đây là khác biệt để đánh US/EU và vẫn tốt ở mobile markets.

## Key risks and mitigations

1. **TikTok downloader legal/policy/ad risk**
   - Mitigation: keep pages compliant, no copyrighted-content language, add terms, consider separating downloader subdomain from AdSense-heavy utility pages.
2. **Head term competition too strong**
   - Mitigation: long-tail locale pages, competitor alternative pages, local use-case pages.
3. **Thin programmatic pages**
   - Mitigation: each page must have real localized copy, FAQ, examples, tool UI, screenshots.
4. **AdSense rejection due to downloader/content policy**
   - Mitigation: launch clean utility pages first; apply with PDF/image/password/QR pages; keep TikTok cluster isolated if needed.
5. **Performance issues with WASM/PDF tools**
   - Mitigation: lazy-load per tool, web workers, file size caps, fallback instructions.
