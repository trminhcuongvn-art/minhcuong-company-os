# Minh Cường Company OS — Core Foundation v0.1

Purpose: operate Minh Cường as an autonomous online product studio for real and digital products.

Core principles:
- 8h block execution.
- WIP max 3 company priorities.
- AI First for low-risk reversible work.
- Evidence Gate: DONE requires path/URL/log/test.
- Stateful workflow over free-form chat.
- Human approval only for high-risk money/data/public/irreversible actions.

Core flow:
Observe -> Decide -> Plan -> Act -> Verify -> Report -> Learn -> Re-plan.
