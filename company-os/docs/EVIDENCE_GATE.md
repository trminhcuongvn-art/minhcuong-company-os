# Evidence Gate

Forbidden report words as completion proof: active, ongoing, priority, studying, planning.

Valid statuses:
- DONE: artifact path/URL + size/log/test + acceptance met.
- PARTIAL: artifact exists but acceptance gap listed.
- BLOCKED: exact blocker + attempts + unblock owner.
- STALLED: no artifact by checkpoint.
- KILLED: stopped with reason.

Learning notes count only if applied to a product/company artifact.
