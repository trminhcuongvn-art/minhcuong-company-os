# Pattern Library

## Evidence Gate Pattern
DONE requires path/URL/log/test. Learning is not delivery unless applied.

## 8h Block Pattern
Nghiệm thu block cũ + plan block mới. WIP max 3.

## Autonomous Loop
Observe -> Decide -> Plan -> Act -> Verify -> Report -> Learn -> Re-plan.

## Multi-agent Scaling Pattern
Permanent core agents stay small; spawn ephemeral workers for subtasks.

## Online Product Pipeline
Offer -> Content/Social -> Lead/RFQ -> CRM -> Sale/Fulfillment -> Analytics -> Improve.
