# Company OS Knowledge Base

Purpose: one searchable place for fragmented research, GitHub findings, tool evaluations, decisions, and phase backlog.

## Index files
- `MASTER_INDEX.md`: top-level index and how to find things.
- `github-research/INDEX.md`: GitHub/project evaluations.
- `tools/TOOL_REGISTRY.md`: tools we may use, status, phase, owner.
- `decisions/DECISION_LOG.md`: decisions already made; do not re-debate unless new evidence.
- `phase-backlog/PHASE_BACKLOG.md`: Phase 1/2/3 usage plan.
- `patterns/PATTERN_LIBRARY.md`: reusable operating/product/agent patterns.

## Required entry format
Every research item must include:
- Name / URL
- Category
- Use case for Minh Cường
- Status: ADOPT / TRIAL / WATCH / REJECT
- Phase: NOW / PHASE_1 / PHASE_2 / LATER
- Owner
- Evidence/source
- Why chosen/rejected
- Next action
